# ArchNet · Shadow Module

Shadow settings for an options menu (type and resolution), applied at once and saved.

- Unity **6000.0** or newer · Needs `com.unity.ugui`, `com.archnet.module.localization` (the ArchNet installer adds them for you).
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/ModuleShadow.git
```

## Use

Drop the **ModuleShadow** prefab into your menu canvas. With URP or HDRP, shadows come from the pipeline asset: use the Video Module's quality level instead.
